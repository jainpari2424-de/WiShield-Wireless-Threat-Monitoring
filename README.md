# WiShield – Wireless Honeypot & Threat Monitoring System

## About the Project
WiShield is a cybersecurity prototype designed to support wireless activity monitoring and basic threat analysis. It combines an ESP8266-based wireless component, a Python Flask backend, an SQLite database, and a web-based dashboard.

## Features
- Device information management
- Wireless activity logging
- SQLite database integration
- Web-based monitoring dashboard
- Rule-based threat analysis

## Technologies Used
- Python
- Flask
- SQLite
- ESP8266
- HTML, CSS, and JavaScript (if used in the implementation)

## Project Status
This project is a prototype developed for learning and demonstrating wireless security monitoring concepts. Features and monitoring capabilities depend on the current implementation.
